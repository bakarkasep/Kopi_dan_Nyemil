# Kopi dan Nyemil (Android, Kotlin + Jetpack Compose)

Buka folder ini di Android Studio (Koala/Ladybug atau lebih baru, JDK 17), tunggu Gradle Sync, lalu Run.
Jika Android Studio menanyakan wrapper, pilih "Use Gradle 8.7" (atau jalankan `gradle wrapper`).

Akun demo: username `kopi`, password `nyemil123`. Atau buat akun lewat Register.
Build APK: `./gradlew assembleDebug` -> app/build/outputs/apk/debug/app-debug.apk
